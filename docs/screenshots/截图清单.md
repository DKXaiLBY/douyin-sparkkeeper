## 截图前的准备（10 分钟，让图好看）

数据已清空，直接截是空白页。按下面造一点演示数据（**纯假数据，无隐私风险**）：

1. 双击 `启动.bat`（后端默认 mock 演练模式，不需要真的抖音账号）
2. 浏览器打开 http://localhost:5173 → 同意协议 → 关掉引导
3. 回仪表盘 → 「火花好友」→「＋ 添加」→ 点 **「🔄 从抖音拉取好友」** → 会列出演示好友（**星星 / 阿茶 / 北北 / 小满 / 图图**）→ 勾选 → 批量添加
4. 顶部「今日待续」→ 点 **「全部发送」**（mock 模式会真的走一遍发送流程并记录，热力图会亮起格子）
5. 数据就有了：成功率 100%、热力图有橙色格子、今日待续显示"已全部续上"

## 截图技巧

- 浏览器 **Ctrl+0** 复位到 100% 缩放（别放大，字会糊），窗口拉宽到 1280–1600px
- **Win + Shift + S** 区域截图，PNG 格式
- 仪表盘全景建议截到完整底部（热力图露出几行 + 图例）
- 液态玻璃的柔光要能看出来——确保背景光球在卡片后面，别在纯色窗口下截

- ❌ 不要截到凭证保险库已解锁状态的界面（含口令输入框也别截）
