# 截图清单

README 顶部引用了 4 张图，请把截图放到本目录，文件名保持一致：

| 文件名 | 截什么 | 怎么截 |
| :--- | :--- | :--- |
| `dashboard.png` | **仪表盘全景**（最重要） | 打开 http://localhost:5173 首页，完整截一屏。这张图决定别人要不要点 Star，务必挑数据最好看的时候截（有连续天数、有成功率环） |
| `friends.png` | 火花好友卡片区 | 截「✨ 火花好友」那块，最好有几个不同连续天数的好友 |
| `heatmap.png` | 续火日历热力图 | 截近 70 天热力图那块，有绿有灰（有断更）显得真实 |
| `settings.png` | 设置页 | 截设置页，能看到文案模板编辑区 |

## 截图建议

- **用 1 倍缩放**（浏览器默认），不要放大，否则字太小看不清
- 宽度建议 1280–1600px，PNG 格式
- 仪表盘那张是整个项目最重要的门面 —— 液态玻璃的质感要能看出来，建议先跑几天积累点数据再截
- 如果担心暴露好友昵称，截图前可以把昵称改成示例名字

## 注意

这些图片会公开到 GitHub，截图前确认没有裸露个人信息（昵称、头像、聊天内容、Cookie 等）。
